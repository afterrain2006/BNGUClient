# 客户端源码

- 找整个页面：`pages`。
- 找页面内组件：`ui`，按操作视野、控制、HUD、消息、设置和通用组件分类。
- 找 MQTT 收发、控制发送、自定义数据接入：`communication`。
- 找机器人/比赛数据：`state/telemetry`；找显示对象、HUD 偏好：`state/ui`。
- 找选择哪套规则、断线时怎样清理、主菜单：`app`。
- 找数据怎样整理成界面显示的值：`telemetry`。
- 找配置默认值、类型和读取辅助：`config`。
- 找界面按钮怎样调用电脑端功能：`desktop`。
- 找具体赛事的协议：不在这里，在根目录 `rules`。
- 找机器人状态、按键等数据格式的共用定义：根目录 `core`。

`main.ts` 仍为前端启动入口。完整目录、旧路径对照和数据流见 [项目地图](../docs/project-map.md)。
