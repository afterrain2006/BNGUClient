# 连接官方选手端和图传

本页说明如何通过官方选手端提供的接口接收机器人状态和视频。机器人编号、账号和网络参数按实际设备配置填写。

## 连接地址怎么选

| 使用方式 | BNGUClient 的 IP 地址 |
| --- | --- |
| 官方选手端与 BNGUClient 在同一台电脑 | `127.0.0.1` |
| 接口由另一台电脑提供 | 提供接口的电脑的实际 IP |
| 使用赛场提供的接口 | 按现场公布的地址填写 |

`127.0.0.1` 表示本机。赛事引擎所在电脑的地址，不一定是自定义客户端的数据接口地址。

默认 MQTT 数据端口为 `3333`，视频接收端口为 `3334`。如果服务端修改了端口，客户端也要对应修改。机器人编号（Client ID）填当前要操作的机器人编号；用户名按服务要求填写。

## 启动和连接

1. 按官方软件说明接好裁判系统、图传收发端和网络。图传接收端通过 USB 接到运行官方选手端的电脑。
2. 按官方包的 `ReadMe.txt` 安装运行环境和图传驱动，从官方包根目录运行 `Start.bat`，启动选手端及配套后台。
3. 在官方选手端登录对应机器人，确认状态和图传正常。使用本机转发接口时，保持官方程序运行。
4. 打开 BNGUClient，按 Esc → 操作中心 → 连接配置 → 网络，填写接口地址、端口和机器人编号，点击服务器地址旁的“连接”。
5. 在“机器人”页选择要查看的机器人。它应与实际连接的机器人对应，不固定为某个队伍或兵种。
6. 使用图传时，在“视频源”页选择 UDP，点击“应用并连接”。确认画面和状态正常后，再启用键鼠控制。

Client ID 决定连接哪台机器人，机器人下拉框决定屏幕显示谁的数据。修改 Client ID 后需断开并重新连接。

本机模拟测试服务与官方程序可能使用相同端口，连接官方程序前应先停止模拟服务。

## 视频由另一台电脑发送时

视频发送端要填写运行 BNGUClient 的电脑的网卡 IP，目标端口与 BNGUClient 的 UDP 监听端口一致。不能把 `127.0.0.1` 当作另一台电脑的地址。

当前网络页的 IP 输入框同时影响 MQTT 连接地址和视频来源筛选。如果状态数据与视频来自不同电脑，需要分别核对设置。

## 常见问题

| 现象 | 检查内容 |
| --- | --- |
| 官方选手端也没有机器人状态 | 赛事引擎连接、主控联网、机器人登录 |
| 官方有状态，BNGUClient 连不上 | 接口地址、MQTT 端口、Client ID，以及是否有其他程序使用同一编号 |
| 官方选手端也没有视频 | 接收端 USB、图传驱动、图传收发端连接 |
| BNGUClient 等待首帧，接收量为 0 | 状态连接、机器人编号、视频来源 IP 和接收端口 |
| 视频接收量增加，但没有输出画面 | 启动终端中的视频解码错误 |
| 画面明显落后 | 对比视频来源，检查是否持续积压；帧率不能直接代表延迟 |

更多处理步骤见 [排错说明](debugging.md)。官方网络和协议要求以对应版本的[官方资料](https://bbs.robomaster.com/wiki/20204847/811363)为准。
