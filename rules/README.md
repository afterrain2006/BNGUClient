# 赛事和队伍的通信规则

当前只有 `rm2026`。它负责解释收到的 RM2026 数据，也负责把按键、鼠标和普通命令变成对方要求的格式。客户端从 `rm2026/index.ts` 使用这些功能，不需要自己到各个内部文件找方法。

真正的消息格式写在 `rm2026/proto/messages.proto`。修改它后，在项目根目录运行 `npm.cmd run generate:mqtt-proto`，生成文件会更新到 `rm2026/generated/mqtt-proto.json`，不要手改生成文件。本机测试服务也读取同一个 proto，避免两边格式不同。

规则只使用共用的数据定义和自己的编解码工具，不读取客户端内部代码。以后有确定的新协议再加文件夹，不提前放一堆空目录。更多位置见 [文件导航](../docs/project-map.md)。
